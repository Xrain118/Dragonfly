# Dragonfly 模型、参数与接口

本说明保留工程的几何、硬件资料、动力学假设及 ROS 接口。当前进度和运行入口见 [工程 README](../../../README.md)。

## 尺寸和坐标

所有长度为米、角度为弧度。集中参数文件：

`src/dragonfly_arm/config/model_dimensions.yaml`

- `measured`：用户提供的机架、动力单元、双臂安装间距，以及机械臂图纸外形尺寸和厂家总质量。
- `arm_kinematics`：RoArm-M3 图纸/源码尺寸、初始姿态和运动关节软件限位，供 Python 与 URDF 共用；末端偏移以新图纸为准。
- `arm_hardware`：12 V 舵机规格、各关节舵机数量、主控与负载能力；桌边夹具只作参考，不进入机载 URDF。
- `arm_dynamics`：六实体质量分配权重，归一化到单臂总质量；各实体惯量按简化几何估算。
- `estimated`：照片估计与第一版设计假设。
- `simulation`：机架质量、倾转限制和慢速演示设置等仿真值；机械臂峰值力矩由 `arm_hardware` 计算。

机体原点为三角形几何中心；+X 指向 A 单元、+Y 向左、+Z 向上。动力单元安装中心的平面坐标为：

| 单元 | X | Y | Z |
|---|---:|---:|---:|
| A | 0.692820 | 0 | 0.06 |
| B | -0.346410 | 0.600000 | 0.06 |
| C | -0.346410 | -0.600000 | 0.06 |

三角形边长为 1.2 m。安装中心高度 0.06 m 为估计值。每组电机沿局部 Y 轴对称设置，轴心距 0.36 m；电机半径暂取 0.015 m、高 0.020 m。每个桨有三片叶片，桨半径 0.116 m；碰撞模型采用同半径的薄圆盘。

倾转运动采用用户接受的近似：
`Rz(单元方位角) × Rx(outer) × Ry(inner)`。两轴相交，outer 为径向，inner 在零位时为切向并随 outer 转动。零位所有桨盘水平；每组双电机随同一支架倾转。旋翼 link 的 +Z 为正推力方向，旋翼 link 的原点在桨毂中心。轴序、轴偏移、硬件零点和真实限位后续均需校准。

两套机械臂底座均位于机体中心下方 0.05 m，分别安装在 `y=+0.15 m`（左臂）和 `y=-0.15 m`（右臂），中心距严格为 0.30 m。中心控制板下方设置一块 `0.14 × 0.40 × 0.012 m` 的连续承载板，覆盖两套基座的完整投影；两根短适配器从承载板底面连续连接至机械臂基座。两臂同向平行安装，均绕 X 轴旋转 π，机械臂基座局部 +Z 朝机腹下方。轴序为：
`底座回转 → 肩俯仰 → 肘俯仰 → 腕俯仰 → 末端轴向旋转`。
关节轴在各自局部坐标系中为 Z、Y、Y、Y、Z；第五关节坐标系含末端安装角，其 +Z 沿末端偏置段方向。

| 区段 | 模型位移向量（m） |
|---|---|
| 基座至肩 | `(0, 0, 0.12606)` |
| 肩至肘，在肩转动后的局部系 | `(0.03000, 0, 0.23682)` |
| 肘至腕，在肘转动后的局部系 | `(0, 0, 0.14449)` |
| 腕至固定工具点，在腕转动后的局部系 | `(0.01329, 0, 0.17167)` |

旧的 0.40 m 总长近似已替换。模型折叠姿态为 `[0, 0, π/2, 0, 0]`，工具点在各自基座坐标系中的位置为 `(0.34616, 0, 0.34959) m`。全零关节角是仿真竖直工作姿态，与折叠姿态不同。当前外部固件的自定义上电姿态另见工程 README。2026-10-09 按用户图纸将末端偏移由源码 `13.69 mm` 改为 `13.29 mm`；Arduino 原文件保持原样，未来接入时需要统一这个 0.40 mm 差异。图纸水平长度 `316.15 mm` 与分段和 `144.49+171.67=316.16 mm` 的 0.01 mm 差异按标注舍入记录，分段长度不改。

简化外形采用图纸大臂横向外廓 37.8 mm、肩部支架高度 53.46 mm、底部板厚 `126.06−123.06=3 mm`；舵机外壳为 `45.22×24.72×35 mm`，肩部有两个舵机外壳。未标注的板宽、厚度、安装细节及腕部轮廓仍为估计；可视与碰撞几何一起更新。图纸桌边固定夹高度 86 mm、外深/内深 92/87.9 mm、外宽/内宽 85.22/81.6 mm，仅作为参考保存。

## 机械臂硬件与动力参数

参数依据：[RoArm-M3 厂家说明](https://docs.waveshare.net/RoArm-M3/)、[ST3215](https://www.waveshare.com/product/st3215-servo.htm)、[ST3215-HS](https://www.waveshare.com/product/robotics/st3215-hs-servo-motor.htm)。

| 项目 | RoArm-M3-S 单臂规格 |
|---|---|
| 自由度 | 5 个运动关节 + 夹爪开合；本项目夹爪固定 |
| 本体质量 | 973.5±15 g，不含桌边固定夹 |
| 桌边固定夹 | 290±10 g，机载模型不安装 |
| 有效负载 | 0.2 kg，距离原点 0.5 m；默认未添加抓取物 |
| 工作空间 | 直径约 1 m，规格描述不是完整可达/无碰撞保证 |
| 底座活动范围 | 360°，模型仍使用有限关节 `[-π,π]` |
| 主控、源码 | ESP32，开源控制与通信程序 |
| 舵机 | ST3215 × 6、ST3215-HS × 1，全塑料外壳 |
| 标称供电 | 本轮按 12 V 参数建模 |
| ST3215 | 峰值 30 kgf·cm = 2.941995 N·m，空载 45 rpm ≈4.712389 rad/s |
| ST3215-HS | 峰值 20 kgf·cm = 1.961330 N·m，空载 106 rpm ≈11.100294 rad/s |

按底座、肩、肘、腕俯仰、末端滚转顺序，每臂峰值限幅为 `[2.941995,5.883990,2.941995,2.941995,2.941995] N·m`；肩关节按两只 ST3215 理想共同输出计算。ST3215-HS 仅驱动夹爪，本轮未新增关节或开合控制。峰值/堵转参数不能视为持续运行力矩；模型未推测热特性或力矩—速度曲线。空载速度与实际轨迹速度分开：固定演示上限仍为 0.6 rad/s，飞行动臂为 0.10 rad/s、0.20 rad/s²。

单臂六实体质量按基座、立柱、大臂、小臂、腕部、夹爪的 `10:8:14:10:6:10` 权重分配，合计严格为 0.9735 kg。权重、各实体质心和惯量仍为估计，不能当作分段称重结果。双臂合计 1.947 kg，承载底板与适配器另计；当前全机标称质量为 5.415 kg。飞行生成器从 URDF 重算质心与全惯量并传给 PX4，`model.json.arm_effort_limits` 按完整关节名称保存十个限幅。

`left_tool0`、`right_tool0` 是源码固定工具参考点，夹爪开合不改变它。各臂关节限位依次为 `±π、±π/2、[0,π]、±π/2、±π`；倾转限位仍为 ±π/2。机械臂限位表示源码控制函数的理想弧度范围，真实舵机端点和零位需标定；肘部原始指令上限 3071 ticks 比理想 π 少一个编码器步。完整坐标定义、公式和实物参考边界见 [RoArm-M3 运动学说明](kinematics.md)。

## 工程组织与接口

- `urdf/dragonfly_arm.urdf.xacro`：整机入口及 ros2_control。
- `urdf/vector_platform.xacro`：三角机架、起落架、倾转单元与三叶桨。
- `urdf/five_axis_arm.xacro`：五轴机械臂与固定夹爪。
- `urdf/geometry_macros.xacro`：几何、惯量和关节接口宏。
- `worlds/model_preview.world`：内置地面和灯光的展示场景，避免启动时依赖在线模型下载。

原四旋翼文件已从有效源码移出，改造前副本保存在工作区 `log/model_before_vector_20260923/dragonfly_quadrotor.urdf.xacro`，不会安装为新模型。

| 接口 | 内容 |
|---|---|
| `/left_arm_controller/follow_joint_trajectory` | `left_joint_1` 至 `left_joint_5`，按此顺序 |
| `/right_arm_controller/follow_joint_trajectory` | `right_joint_1` 至 `right_joint_5`，按此顺序 |
| `/tilt_controller/follow_joint_trajectory` | A outer/inner、B outer/inner、C outer/inner |
| `/joint_states` | 16 个受控关节的位置、速度状态 |
| `/left_arm/tool_pose`、`/right_arm/tool_pose` | `PoseStamped`，分别以 `left_base_link`、`right_base_link` 为参考系 |
| `/left_arm/solve_ik`、`/right_arm/solve_ik` | `dragonfly_arm/srv/SolveIK`，仅返回逆解，不发送运动命令 |
| `/tf`、`/tf_static`、`/robot_description` | 全机坐标与模型 |

倾转关节完整名称为 `unit_a_outer_joint`、`unit_a_inner_joint`，B/C 同理。
原 `/arm_controller/...` 接口不再保留。旧单臂或六轴命令必须改为左右两个五关节接口；不存在 `joint_6`，夹爪不参与运动控制。
